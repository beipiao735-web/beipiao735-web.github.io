关于「免费」，先说清三件事

「完全免费」「免费额度」「部分免费」有什么区别？
完全免费 = 核心功能长期免费用，比如 DeepSeek、豆包的对话。免费额度 = 给你一笔免费量（次数、魔粒、Token），用完要付费，比如魔搭、英伟达 NIM。部分免费 = 平台里一部分模型/功能免费，其余收费，比如硅基流动、OpenRouter——挑带免费标记的用就行。
为什么有的标「需海外网络」？
本站读者很多在国内。标「国内直连」的在国内网络打开就能用；标「需海外网络」的（如 ChatGPT、Google AI Studio、Groq）在国内直连打不开，需要海外网络环境，自己提前确认好再注册，省得卡在第一步。
免费 API 的 Key 能商用吗？
多数不能，或者有限制。比如 NVIDIA NIM 的免费 Key 仅限开发测试，调用内容会被留存，别拿它处理隐私数据；Pollinations 匿名调用也有频率限制。各家的条款以官网为准，真要商用先看清规则，或者直接上付费档。
「免费搜索 API」分类的额度准吗？
本分类额度来自 linux.do 社区帖（2026-11-16），未逐家官方核实，以各官网为准。其中 Keenable、AnySearch、Serpex 三家已与官方口径对上；其余如 Linkup、Tavily、Exa 等的免费层经常调整，注册前请再到官网确认。分类里 DeepSeek 官方搜索是付费项（¥5/千次、无免费额度），Serper 与 Serpex 是一次性额度，用完不续杯，请注意区分。
